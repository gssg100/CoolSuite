# CoolSuite (쿨스위트) - 교사용 쿨메신저 업무 편의 도구

교사를 위한 쿨메신저 업무·수업 집중 및 편의 유틸리티 모음입니다.

**제작자**: 수지샘 (`lemrlog@gmail.com`)  
**지원 OS**: Windows 10, Windows 11 (.NET Framework 4.0 이상)

---

## 📦 구성 프로그램

### 1. CoolKeeper (쿨메신저 상시 자리비움)
* **목적**: 수업 및 중요한 교무 업무 중 쿨메신저 쪽지/알림으로 인한 방해 차단
* **기능**:
  * 쿨메신저 접속 상태를 실시간 감지하여 자동으로 **'잠시 비움'** 상태 유지
  * 윈도우 시작 시 자동 실행 및 시스템 트레이 최소화
  * 관리자 권한 불필요, 단일 파일 실행
  * **원클릭 자동 업데이트 지원**

### 2. CoolDownloader (쿨메신저 첨부파일 5초 자동 다운로더)
* **목적**: 쏟아지는 교내 메신저 쪽지의 첨부파일을 일일이 저장 누를 필요 없이 자동 수신
* **기능**:
  * 새 쪽지 수신 시 **5초 카운트다운 알림창** 표시
  * 카운트다운 중 취소하지 않으면 모든 첨부파일을 지정 폴더에 자동 일괄 다운로드
  * **철통 5중 중복 다운로드 방지**: 이미 받은 파일 재다운로드 원천 차단
  * **원클릭 자동 업데이트 지원**
