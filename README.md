# CoolSuite (쿨스위트) - 교사용 쿨메신저 올인원 편의 도구

교사를 위한 쿨메신저 업무·수업 집중 및 모바일 편의 유틸리티 3총사 모음입니다.

**공식 제작자**: 수지샘 (`lemrlog@gmail.com`)  
**지원 OS**: Windows 10, Windows 11 (.NET Framework 4.0 이상)  
**공식 저장소**: [https://github.com/gssg100/CoolSuite](https://github.com/gssg100/CoolSuite)

---

## 📦 구성 프로그램 (3총사)

### 1. CoolKeeper (쿨메신저 상시 자리비움)
* **목적**: 수업 및 중요한 교무 업무 중 쿨메신저 쪽지/알림으로 인한 방해 차단
* **기능**:
  * 쿨메신저 접속 상태를 실시간 감지하여 자동으로 **'잠시 비움'** 상태 유지
  * 윈도우 시작 시 자동 실행 및 시스템 트레이 최소화
  * 관리자 권한 불필요, 단일 파일 실행
  * **원클릭 자동 업데이트 지원**

### 2. CoolDownloader (쿨메신저 첨부파일 5초 자동 다운로더)
* **목적**: 쏟아지는 교내 메신저 쪽지의 첨부파일을 일일이 저장 누를 필요 없이 자동 수신
* **기능**:
  * 새 쪽지 수신 시 **5초 카운트다운 알림창** 표시
  * 카운트다운 중 취소하지 않으면 모든 첨부파일을 지정 폴더에 자동 일괄 다운로드
  * **철통 5중 중복 다운로드 방지**: 이미 받은 파일 재다운로드 원천 차단
  * **원클릭 자동 업데이트 지원**

### 3. CoolNotifier (쿨메신저 모바일 실시간 알림 전달) ⭐ NEW!
* **목적**: 교실 자리비움, 출장, 수업 중 컴퓨터 쿨메신저로 온 쪽지를 내 스마트폰으로 실시간 수신
* **기능**:
  * **100% 무결점 감지**: 윈도우 네이티브 SQLite 실시간 감지 엔진 탑재 (모니터 꺼짐, 컴퓨터 잠금 Win+L 상태에서도 100% 감지)
  * **다중 모바일 채널 지원**: 텔레그램 봇(Telegram) 및 디스코드(Discord) 웹훅 지원
  * **학교 현장 안심 모드**:
    * 전체 모드: 발신자 + 일시 + 제목 + 본문 전문 + 첨부파일명
    * 안심 모드: 발신자 + 일시 + 제목만 전달 (학생 개인정보 보호를 위해 본문 제외)
    * 단순 알림 모드: 새 쪽지 수신 알림만 간단히 전달
  * **중요 쪽지 키워드 필터링**: `[긴급]`, `[공지]`, `교무` 등 지정 키워드 포함 쪽지만 선별 수신
  * **퇴근 후 & 주말 방해금지 시간대 설정**: 야간이나 주말에 폰 알림 차단
  * **원클릭 자동 업데이트 지원**
